## 플랫폼 장점

- **1위안 = 1달러**: 위안화 충전 시 1:1로 달러 크레딧 전환, 합리적인 가격
- **다양한 모델**: GPT / Claude / Gemini / Grok / DeepSeek / GLM / Kimi / Doubao Seed
- **동영상 모델**: Seedance 2.0 / 2.5, MiniMax H3, Wan 3.0, Veo 3.1, 초 단위 또는 token 단위 과금
- **셀프 세금계산서 발행**: 관리 화면에서 티켓 제출로 중국 **증치세 전용 세금계산서** 및 **일반 세금계산서** 발행
- **기업 협력**: SLA 보장 기업 전용 라인, 법인 계좌 이체 지원
- **다양한 그룹**: 동일 모델에 여러 라인 / 그룹 제공, 가격과 안정성 중 선택 가능

## 요금 안내

```
실제 결제가 = 정가 × 그룹 배율
```

아래 가격 단위는 **달러 / 100만 tokens**(초 단위 동영상 제외)이며, 표기는 `실제 결제가 (정가)`입니다. 가격은 수시로 변경될 수 있으며 **공식 사이트의 실시간 가격이 우선합니다**.

**공식가 대비 얼마나 저렴한가요?** 공식가는 달러 기준이지만 본 플랫폼은 **1위안 = 1달러 크레딧**이며, 사용 시 그룹 배율을 곱합니다. 1달러 ≈ 7.1위안 기준:

**실제 비용 ≈ 공식가 × 배율 ÷ 7.1**

예: 0.3x 그룹은 0.3 ÷ 7.1 ≈ 공식가의 **4.2%**.

## 빠른 시작

1. [https://www.fastaitoken.com/](https://www.fastaitoken.com/) 에서 회원가입
2. 충전 (1위안 = 1달러 크레딧)
3. 콘솔에서 API 키를 생성하고 그룹 선택
4. 키와 콘솔에 표시된 Base URL을 앱 / SDK / 코딩 도구에 설정하여 호출

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",  # FastAIToken 콘솔에서 생성
    base_url="<콘솔에 표시된 Base URL>",
)

resp = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "안녕하세요!"}],
)
print(resp.choices[0].message.content)
```
