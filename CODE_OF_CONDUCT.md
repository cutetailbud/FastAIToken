# Code of Conduct / 行为准则

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。
This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## 我们的承诺 / Our pledge

无论年龄、体型、残疾、民族、性别认同、经验水平、国籍、外貌、种族、宗教或性取向，我们都致力于让每个人在参与本项目时免受骚扰。
We pledge to make participation in this project a harassment-free experience for everyone.

## 期望的行为 / Expected behavior

- 友善、尊重不同观点 / Be kind and respectful of differing viewpoints
- 接受建设性的批评 / Accept constructive feedback gracefully
- 关注对社区最有利的事 / Focus on what is best for the community

## 不可接受的行为 / Unacceptable behavior

- 骚扰、人身攻击、歧视性言论 / Harassment, personal attacks, discriminatory language
- 未经许可公开他人隐私信息 / Publishing others' private information
- 发布广告、垃圾信息或他人的 API Key / Spam, ads, or posting anyone's API keys

## 执行 / Enforcement

违规行为可通过 [https://www.fastaitoken.com/](https://www.fastaitoken.com/) 后台工单向维护者举报。维护者有权删除评论、关闭 Issue 或封禁违规者。
Report violations to the maintainers via a ticket on the website. Maintainers may remove content or ban participants who violate this code.
