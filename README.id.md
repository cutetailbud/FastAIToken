## Penagihan

```
Harga dibayar = Harga daftar × Pengali grup
```

Semua harga di bawah dalam **USD per 1M token** (kecuali video per detik), ditampilkan sebagai `harga dibayar (harga daftar)`. Harga dapat berubah sewaktu-waktu — **harga di situs web yang berlaku**.

**Seberapa murah dibanding harga resmi?** Harga resmi dalam USD, sedangkan di sini **1 CNY = kredit 1 USD**, lalu pemakaian dikalikan pengali grup. Dengan kurs 1 USD ≈ 7.1 CNY:

**Biaya nyata ≈ harga resmi × pengali ÷ 7.1**

Contoh grup 0.3x: 0.3 ÷ 7.1 ≈ **4.2%** dari harga resmi.

## Mulai Cepat

1. Daftar di [https://www.fastaitoken.com/](https://www.fastaitoken.com/)
2. Isi saldo (1 CNY = kredit 1 USD)
3. Buat API key di konsol dan pilih grup
4. Masukkan key dan Base URL dari konsol ke aplikasi / SDK / alat coding Anda

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",  # dibuat di konsol FastAIToken
    base_url="<Base URL dari konsol>",
)

resp = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Halo!"}],
)
print(resp.choices[0].message.content)
```
