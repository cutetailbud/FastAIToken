# FastAIToken

> ワンストップ大規模言語モデル API 統合プラットフォーム —— **[https://www.fastaitoken.com/](https://www.fastaitoken.com/)**

FastAIToken は国内外の主要な大規模言語モデルと動画生成モデルを統合しています。1 つのアカウント・1 つの API キーで GPT、Claude、Gemini、Grok、DeepSeek、GLM、Kimi、さらに Seedance、MiniMax H3、Wan 3.0、Veo 3.1 などの動画モデルを利用できます。

## ✨ プラットフォームの特長

- 💱 **1 人民元 = 1 米ドル**：人民元でのチャージを 1:1 で米ドル残高に交換、お得な価格
- 🧠 **豊富なモデル**：GPT / Claude / Gemini / Grok / DeepSeek / GLM / Kimi / Doubao Seed
- 🎬 **動画モデル**：Seedance 2.0 / 2.5、MiniMax H3、Wan 3.0、Veo 3.1。秒単位または token 単位で課金
- 🧾 **セルフ請求書発行**：管理画面からチケットを送るだけで中国の**増値税専用発票**・**普通発票**を発行
- 🏢 **法人向け**：SLA 付き法人専用ライン、法人口座からの振込に対応
- 🔀 **複数グループ**：同一モデルに複数のライン / グループを用意し、価格と安定性を選択可能

## 🧮 料金について

**支払価格 = 定価 × グループ倍率**

以下の価格単位は **米ドル / 100 万 tokens**（秒課金の動画を除く）、表記は `支払価格（定価）` です。価格は随時変更される場合があります。**公式サイトの最新価格が優先されます**。

💡 **公式価格の何割？** 公式価格は米ドル建てですが、当プラットフォームは **1 人民元 = 1 米ドル分**、利用時にグループ倍率を掛けます。1 米ドル ≈ 7.1 人民元とすると：

**実質コスト ≈ 公式価格 × 倍率 ÷ 7.1**

例：0.3x グループは 0.3 ÷ 7.1 ≈ 公式価格の **4.2%**。

## 🚀 クイックスタート

1. [https://www.fastaitoken.com/](https://www.fastaitoken.com/) にアクセスしてアカウント登録
2. チャージ（1 人民元 = 1 米ドル分）
3. コンソールで API キーを作成し、グループを選択
4. キーとコンソールに表示される Base URL をアプリ / SDK / コーディングツールに設定して呼び出し

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",  # FastAIToken コンソールで作成
    base_url="<コンソールに表示される Base URL>",
)

resp = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "こんにちは！"}],
)
print(resp.choices[0].message.content)
```
