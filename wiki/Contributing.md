# 参与贡献 / Contributing

本 Wiki、README 与 `pricing.json` 都由 `scripts/readme/` 中的脚本生成，**请勿在 Wiki 网页上直接编辑**，否则下次同步时会被覆盖。
This wiki, the READMEs and `pricing.json` are all generated by `scripts/readme/`. **Do not edit the wiki in the browser**: changes are overwritten on the next sync.

| 修改内容 To change | 编辑文件 Edit |
| :--- | :--- |
| 价格、模型 / Prices, models | `scripts/readme/data.py` |
| README 文案 / README wording | `scripts/readme/i18n.py` |
| 汇率、折扣文案 / Exchange rate, discount wording | `scripts/readme/extra.py` |
| README 排版、`pricing.json` 结构 / README layout, `pricing.json` schema | `scripts/readme/gen.py` |
| Wiki 页面 / Wiki pages | `scripts/readme/wiki.py` |

```bash
python scripts/readme/gen.py .            # 重新生成 / regenerate
python -m unittest discover -s tests      # 测试 / test
python scripts/readme/gen.py . --check    # CI 检查 / what CI runs
```

合并到 `master` 后，`Wiki` 工作流会把 `wiki/` 目录同步到 GitHub Wiki。
After merging to `master`, the `Wiki` workflow syncs the `wiki/` directory to the GitHub Wiki.
