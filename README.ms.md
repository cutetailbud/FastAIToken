## Pengebilan

```
Harga dibayar = Harga senarai × Pengganda kumpulan
```

Semua harga di bawah dalam **USD bagi setiap 1M token** (kecuali video per saat), dipaparkan sebagai `harga dibayar (harga senarai)`. Harga boleh berubah pada bila-bila masa — **harga di laman web adalah muktamad**.

**Berapa murah berbanding harga rasmi?** Harga rasmi dalam USD, tetapi di sini **1 CNY = kredit 1 USD**, kemudian penggunaan didarab dengan pengganda kumpulan. Pada kadar 1 USD ≈ 7.1 CNY:

**Kos sebenar ≈ harga rasmi × pengganda ÷ 7.1**

Contoh kumpulan 0.3x: 0.3 ÷ 7.1 ≈ **4.2%** daripada harga rasmi.

## Mula Pantas

1. Daftar di [https://www.fastaitoken.com/](https://www.fastaitoken.com/)
2. Tambah nilai (1 CNY = kredit 1 USD)
3. Cipta API key di konsol dan pilih kumpulan
4. Tetapkan key dan Base URL dari konsol dalam aplikasi / SDK / alat pengaturcaraan anda

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",  # dicipta di konsol FastAIToken
    base_url="<Base URL dari konsol>",
)

resp = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Helo!"}],
)
print(resp.choices[0].message.content)
```
