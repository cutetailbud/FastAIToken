## 🧮 Тарификация

**Фактическая цена = Базовая цена × Множитель группы**

Все цены ниже указаны в **USD за 1M токенов** (кроме посекундной оплаты видео), в формате `фактическая цена (базовая цена)`. Цены могут меняться — **актуальными считаются цены на сайте**.

💡 **Насколько дешевле официальной цены?** Официальные цены указаны в долларах, а у нас **1 юань = 1 доллар баланса**, затем расход умножается на множитель группы. При курсе 1 USD ≈ 7.1 CNY:

**Фактическая стоимость ≈ официальная цена × множитель ÷ 7.1**

Например, группа 0.3x: 0.3 ÷ 7.1 ≈ **4.2%** от официальной цены.

## 🚀 Быстрый старт

1. Зарегистрируйтесь на [https://www.fastaitoken.com/](https://www.fastaitoken.com/)
2. Пополните баланс (1 юань = 1 доллар)
3. Создайте API-ключ в консоли и выберите группу
4. Укажите ключ и Base URL из консоли в своём приложении / SDK / инструменте для разработки

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",  # создаётся в консоли FastAIToken
    base_url="<Base URL из консоли>",
)

resp = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Привет!"}],
)
print(resp.choices[0].message.content)
```
